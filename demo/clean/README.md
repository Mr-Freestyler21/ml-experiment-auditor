# Clean demo project

A hospital readmission model that is evaluated correctly: patients are kept apart with a
grouped split (no patient appears in both training and test), the model is fitted on the
training rows only, and every feature is known at discharge. One feature,
`num_prior_readmissions`, predicts readmission strongly, and legitimately: it is known at
discharge. The auditor should answer
**not found** here: a strong feature is not a leak, and an honest experiment should not
be accused.

The data is synthetic, generated by `benchmark/generate.py`.

```bash
python -m auditor.cli audit demo/clean
```
